# Open RNG Engine

**The open-source gold standard RNG for casino games, poker, slots and iGaming.**

Free, certifiable core that game developers can use for poker, Super Hold'em, blackjack, roulette, Megaways slots, bonus spins and any new variation — right up to deployment and certification.

Built in alignment with **GLI-19 v4.0** and **NIST SP 800-90A** so it can approach formal certification later.

## Why this exists

There is no mature, widely-used open-source RNG engine on GitHub that developers can simply fork and build real-money or social casino games on. Existing projects are small, crypto-only or incomplete.

This project fills that gap.
